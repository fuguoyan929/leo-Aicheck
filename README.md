# leo-Aicheck

面向中文和英文经济学学术论文的去模板化与清晰表达审校技能。

保留事实、术语、识别逻辑和证据强度，处理空泛表达、重复、难读句子及不必要的防御性写作。目标是平实、直接、准确；不提供作者来源鉴定或检测分数保证。

## 安装

将完整文件夹复制到Codex的用户级全局技能目录，文件夹名使用leo-aicheck，确保其中直接包含SKILL.md。

本次安装采用用户目录下的.codex/skills/leo-aicheck，供不同项目调用，无需放入内置技能的.system子目录。如本机另设CODEX_HOME，使用相应的skills目录。

内部标识为leo-aicheck；界面名称为leo-Aicheck。内部名称使用小写以符合技能格式校验。

## 使用

- 使用 $leo-aicheck 审校以下经济学论文，逐处指出问题并给出修改稿。
- 使用 $leo-aicheck 仅诊断这段摘要，区分必要修改、风格建议和待核实事项。
- 使用 $leo-aicheck 直接改写以下英文段落，保留术语、数字和证据强度。
- 使用 $leo-aicheck 只修正中文标点和空格，不改措辞与结论。

允许自动匹配相关审校请求，也支持明确调用。安装后若当前会话未显示技能，可在新会话中检查技能列表。

## 文件

- SKILL.md：触发条件、核心规则、工作流程与输出要求。
- agents/openai.yaml：界面名称、默认提示与自动调用设置。
- references/language-checks.md：词语与句式检查表。
- references/examples.md：边界示例和行为检查。

无需外部检测服务、额外插件或联网即可处理用户提供的文本。引用核验或文献检索应在用户请求范围内另行处理。

上传GitHub时保留目录结构即可。仓库许可证由发布者选择，本技能包未代为指定许可证。
