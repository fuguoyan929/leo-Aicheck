# 词语与句式判断

本表用于定位需要阅读上下文的位置，不是禁词表。不按词频推算AI概率，不进行全文机械替换。

## 英文表达

| 表达 | 判断与处理 | 应保留的情况 |
|---|---|---|
| utilize | 普通“使用”优先写use | 原文引语或确有词义差别 |
| leverage | 根据实际动作写use、draw on等，不凭空补入“外生变化” | financial leverage等专业概念 |
| facilitate | 说清帮助谁做什么；没有机制证据时不自行具体化 | 准确表达促进作用时 |
| delve into | 通常用examine、study等直接动词 | 必须保真的引文 |
| landscape | 用具体领域、市场或制度背景替代空泛用法 | 地理研究、引文或有明确含义的概念 |
| robust | 用实际检验及结果说明稳健性，避免无依据赞美 | robust standard errors等术语 |
| crucial / pivotal / transformative | 检查程度是否有依据，普通事实不升级为重大突破 | 有具体支持且程度准确时 |
| conduct an analysis of | 通常可用analyze | 需要强调该项分析工作本身时 |
| may / suggest / consistent with | 检查不确定性来源，减少叠加的缓和词 | 证据只能支持有限结论时 |

## 中文表达

| 表达 | 默认检查 | 处理原则 |
|---|---|---|
| 毋庸置疑、众所周知 | 无依据替读者下结论 | 通常删除，必要时提供已有来源；不编引用 |
| 总而言之、值得一提的是 | 是否只宣布总结或强调 | 无信息则删除；保留必要结构提示 |
| 仿佛、似乎、在一定程度上 | 比喻或不确定性是否有具体含义 | 有证据则具体化；证据不足时保留适当限定 |
| 不难看出、由此可见 | 推理是否成立 | 直接说结论及依据；不改成虚构个人体验 |
| 深入探讨、赋能、抓手、闭环 | 是否用抽象词代替对象和作用 | 用已有内容说明对象、动作或结果；缺失信息标注待核实 |
| 重要且关键、显著且明显 | 两个词是否增加不同信息 | 删除同义重复；保留统计显著性含义 |
| 此外、然而、首先、其次 | 是否承担真实逻辑功能 | 保留有用连接，不为“去AI”删掉逻辑 |
| 本文认为、本文指出、本文提出 | 连续自指是否遮住研究内容 | 合并冗余，允许本文或我们作方法、贡献句的主语 |
| 遗憾的是、效果有限、仍明显落后 | 情绪评价或含糊比较 | 报告原稿已有的事实、指标和范围 |
| 仅、只 | 是否限定样本、对象、条件或参数 | 保留实质限定；删除多余贬低语气 |

## 句式和格式

- “不是X，而是Y”：保留真实概念区分，删除无人主张过的假对立。
- “有人可能认为”：有明确文献争论时准确归属，否则删除虚构反对者。
- 三项排比：检查是否真有三个不同信息，不人为凑数或拆散合理并列。
- 同主语连续起句：累赘时合并，避免造成主语或指代不明。
- 长句：识别主干及条件再拆分，保留识别假设、比较基准和修饰对象。
- 装饰性引号：普通口号可删除或改具体；直接引语、术语定义、名称及有概念功能的引号保留。
- 标点混用：区分正文、公式、代码、引文、英文题名及期刊格式后处理。
- “希望这能帮到你”等助手尾句：从论文中删除；研究AI对话本身时，保留作为研究材料的真实引语。
- 专业名称、模型名、变量名、引用和数据截止日期不因“像AI”而改动。
